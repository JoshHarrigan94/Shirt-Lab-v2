# Roadmap

## Current pass

This pass focuses on:

- stronger cinematic stage presentation
- clearer control and results drawers
- garment DNA
- scenario presets
- expanded scores
- comparison mode
- evidence-ready reasoning structures

## Next pass

Recommended next upgrades:

1. Add a clearer stage timeline
   - resting
   - loading
   - saturated
   - recovery

2. Improve comparison storytelling
   - side-by-side mini shirt visual cards
   - scenario sweep comparison
   - "wins in dry / loses in humid" summary matrix

3. Deepen evidence structures
   - evidence tags by mechanism
   - calibration notes
   - simple source cards in the results drawer

4. Improve visual fidelity
   - richer mapped wetness masks
   - more nuanced heat zoning
   - optional split-view stage for Shirt A vs Shirt B

5. Add validation utilities
   - debug overlay for internal feature signals
   - hidden tuning panel for ontology weights
   - exported JSON snapshot of current scenario and scores

## Long-term direction

ShirtLab should evolve toward a premium garment concept sandbox:

- believable visual persuasion
- explainable heuristic reasoning
- calibration-ready evidence model
- scenario-aware comparison

It should not drift into either:

- fake scientific certainty
- generic shader spectacle with weak decision value
